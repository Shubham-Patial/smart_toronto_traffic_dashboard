# Smart Toronto Traffic Data Dashboard

An interactive data visualization dashboard analyzing traffic congestion, accidents, and weather patterns in Toronto.

## Tech Stack
- Python
- Pandas
- Streamlit
- Plotly
- SQL (SQLite)
- APIs (Toronto Open Data, OpenWeatherMap)
